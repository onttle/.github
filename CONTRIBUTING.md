# Contributing

Thanks for taking the time to help.

## Issues

- Search existing issues first.
- Issues here are for the code in these repositories. For the Onttle service itself, email [support@onttle.com](mailto:support@onttle.com).
- Never paste API keys, tokens or personal data into an issue.

## Pull requests

- Changes go in through a pull request to `main`. Keep each one to a single purpose.
- Say what changed and how you checked it.
- Do not commit secrets. Put configuration in `.env.local` and document the variable names in `.env.example`.
- If the repository has an `AGENTS.md`, its rules apply to people and coding agents alike.

---

## 기여 안내

- 이슈는 이 조직 repo의 코드에 대한 것만 받습니다. 서비스 문의는 [support@onttle.com](mailto:support@onttle.com)으로 보내 주세요.
- 변경은 `main`으로 향하는 PR로 보내고, PR 하나에는 한 가지 목적만 담습니다.
- API 키 등 시크릿은 이슈나 커밋에 넣지 않습니다.
- repo에 `AGENTS.md`가 있으면 그 규칙을 따릅니다.

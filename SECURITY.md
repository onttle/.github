# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email [support@onttle.com](mailto:support@onttle.com) with the subject line starting with `[Security]`, and include:

- What is affected (the Onttle service, or a repository and file in this organization)
- Steps to reproduce
- What an attacker could do with it

We will confirm that we received your report and keep you updated until it is resolved. Please give us time to fix the problem before you disclose it publicly.

## Secrets in example code

The repositories here are examples. If you find an API key or other secret committed to one of them, report it the same way so that we can revoke it.

## 보안 정책

보안 문제는 공개 이슈로 올리지 말고 [support@onttle.com](mailto:support@onttle.com)으로 보내 주세요. 제목을 `[Security]`로 시작하고, 영향 범위, 재현 방법, 예상되는 피해를 적어 주시면 됩니다. 접수 사실을 알려 드리고 해결될 때까지 진행 상황을 공유합니다. 수정 전까지는 공개를 미뤄 주세요.

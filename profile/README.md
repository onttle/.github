# Onttle

**The headless CMS that AI works alongside.** Describe what you're building and AI designs the tables. Your CMS and REST API are ready instantly.

[Website](https://onttle.com) · [Docs](https://onttle.com/docs) · [Blog](https://blog.onttle.com) · [Live examples](https://example.onttle.com) · [Get started free](https://app.onttle.com/signup)

## What you get

- **Structured data + REST API** — define tables and column types, and serve them over a REST API with an OpenAPI 3.0 spec generated for every project.
- **Auto-generated CMS** — content screens and input forms follow your table schema.
- **AI and vector search** — content generation and semantic search built in.
- **Translations, variables, file storage** — the pieces a real site needs, behind the same API.
- **MCP server** — let Claude, Claude Code or Cursor read and change your project directly. See the [MCP docs](https://onttle.com/docs/ai/mcp).

## 한국어

**AI가 함께 일하는 헤드리스 CMS.** 만들고 싶은 것을 설명하면 AI가 테이블을 설계하고, CMS와 REST API가 바로 준비됩니다.

[웹사이트](https://onttle.com) · [문서](https://onttle.com/docs) · [블로그](https://blog.onttle.com) · [라이브 예제](https://example.onttle.com) · [무료로 시작하기](https://app.onttle.com/signup)

- **구조화된 데이터 + REST API** — 테이블과 컬럼 타입으로 데이터를 관리하고, 프로젝트마다 OpenAPI 3.0 명세가 자동 생성됩니다.
- **자동 생성 CMS** — 테이블 스키마에 맞춰 콘텐츠 관리 화면과 입력 폼이 만들어집니다.
- **AI·벡터 검색** — 콘텐츠 생성 자동화와 시맨틱 검색을 기본 제공합니다.
- **번역·변수·파일 스토리지** — 실제 사이트에 필요한 요소를 같은 API로 제공합니다.
- **MCP 서버** — Claude, Claude Code, Cursor에서 프로젝트를 직접 조회하고 변경할 수 있습니다. [MCP 문서](https://onttle.com/docs/ai/mcp)

예제 코드는 [onttle-examples](https://github.com/onttle/onttle-examples)에 있습니다. 서비스 문의는 [support@onttle.com](mailto:support@onttle.com)으로 보내 주세요.

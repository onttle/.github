# .github

Organization-wide files for [Onttle](https://github.com/onttle).

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The profile shown on https://github.com/onttle |
| `SECURITY.md` | Default security policy for every repository |
| `SUPPORT.md` | Default support guide for every repository |
| `CONTRIBUTING.md` | Default contribution guide for every repository |
| `.github/ISSUE_TEMPLATE/` | Default issue forms |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |

A repository that has its own copy of one of these files uses its own copy instead.
